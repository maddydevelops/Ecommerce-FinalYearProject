# MERN Stack E-commerce Application

This is a full-featured E-commerce application built with the **MERN Stack**, using:

- **React.js** (frontend)
- **Node.js** and **Express.js** (backend)
- **MongoDB** (database)
- **Redux Toolkit** and **RTK Query** (state management and data fetching)
- **TypeScript** (type safety)
- **Stripe** (payment processing)
- **Multer** (file uploads)

---

## 🎯 Features

✅ Browse and shop for clothes, accessories, and home goods  
✅ User authentication and authorization  
✅ Shopping cart management  
✅ Order processing with Stripe payments  
✅ Product image uploads with Multer  
✅ REST API built with Express  
✅ Fully responsive frontend built in React  
✅ State management with Redux Toolkit and RTK Query  
✅ Typed codebase using TypeScript
